\# WatchGuard AI



Multimodal real-time threat detection system combining:



\- YOLOv8 (object detection)

\- CLIP (semantic reasoning)

\- Optical flow (motion analysis)

\- Audio classification (YAMNet)



\## Architecture



Camera → YOLO → CLIP → Motion → Audio → Fusion → Alert



\## Features



\- Real-time threat scoring

\- Event-based recording

\- Multimodal fusion



\## Limitations



\- No temporal deep learning (LSTM/transformer)

\- CLIP works per frame (no motion awareness)
